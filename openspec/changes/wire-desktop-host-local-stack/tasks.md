## TDD contract

Public seams for this change: the Desktop Host Contribution loader (`createDesktopHostContributionLoader`), the existing `DesktopHostContributionRuntime.load` boundary, the Codex package's `createProviderContribution` entry, and the bundled-Relay environment builder (`buildRelayEnv`). Every RED step creates the named test and its stated behavioral assertion; a missing module or a syntax error does not count as RED. The change opts out of specs (`skip_specs`), so there are no spec deltas to keep in step.
