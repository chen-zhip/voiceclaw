## TDD contract

The public seams below were confirmed during the pre-apply review. Every RED step first creates the named test and stated behavioral assertion. Missing tests, discovery failures, syntax errors, unavailable optional credentials, or unrelated setup failures do not count as RED. Each GREEN step is limited to its named vertical behavior and reruns the same command after local cleanup. Optional real-system tests skip with an explicit reason unless their declared environment is present.
