## TDD contract

The public seams below were confirmed during the pre-apply review. Every RED step first creates the named test and stated behavioral assertion. Missing tests, discovery failures, syntax errors, or unrelated setup failures do not count as RED. Each GREEN step is limited to its named behavior and reruns the same command after local cleanup.

## 1. Remote and local Host identity

- [ ] 1.1 Public seam: remote Host enrollment exchange. First create `relay-server/test/desktop-host/host-enrollment.test.ts` asserting owner authorization, short expiry, single consumption, per-install Host ID, plaintext credential return only once, and persisted verifier through `ControlStateStore`. RED: run `yarn workspace relay-server vitest run test/desktop-host/host-enrollment.test.ts -t "exchanges one enrollment token once"` and confirm enrollment behavior is absent. GREEN: implement only token issue/exchange and typed registration persistence. Verify with the same command.
- [ ] 1.2 Public seam: remote Host WSS authentication. First create `relay-server/test/desktop-host/host-connection.test.ts` asserting a valid per-install Host Credential authenticates the Host Principal after Relay restart while invalid, expired, or revoked material is rejected and Client/Provider credentials cannot substitute. RED: run `yarn workspace relay-server vitest run test/desktop-host/host-connection.test.ts -t "authenticates only the registered remote Host"` and confirm Host authentication is absent. GREEN: implement only credential verification and outbound WSS admission. Verify with the same command.
- [ ] 1.3 Public seam: bundled local Host authentication. First extend `host-connection.test.ts` to assert a per-startup non-persisted Local Host Bootstrap Secret authenticates only the owning bundled stack, expires on exit, and causes no Host Credential issue or persisted verifier. GREEN: implement only the controlled local bootstrap path. Verify with the same command.
- [ ] 1.4 Public seam: owner Host management. First create `relay-server/test/desktop-host/host-management.test.ts` asserting owner-only Host ID/status/last-activity inspection, revocation persisted through restart, and re-registration without credential disclosure.
