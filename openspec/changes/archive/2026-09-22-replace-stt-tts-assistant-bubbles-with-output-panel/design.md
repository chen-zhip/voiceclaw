## Context

动机见 proposal.md。`ChatPage.tsx` 将完成消息交给 `MessageBubble`，流式文字和等待提示则内联绘制气泡。页面已有时间线排序、附件映射、消息菜单和暂停跟随滚动能力。语音模式目前主要在启动路径读取，尚无统一的展示模式状态。

固定评审比较点：`2264f0af6186abd25cf8185d635cf049f6ad3239`。规划开始时工作区已有大量未提交改动，包括 ChatPage、use-realtime、Desktop 测试配置和其他 OpenSpec changes；它们是已有工作，不属于本变更。实现前记录相关文件的已有 diff，最终评审同时使用固定 Git 点、本变更文档和该 diff 区分归属，不覆盖已有实现。

遵循 Desktop CONTEXT、CONTEXT-MAP、ADR-0002（历史权威）和 ADR-0006（保留 Harness speech）。本改动只改变当前 Desktop 消息投影的展示，不定义新存储权威，不改写 speech。文本输出面板为普通 UI 描述，不新增领域概念或架构边界，因此无需新增 CONTEXT 术语或 ADR。

## Goals / Non-Goals

**Goals:** 以一致的 AI 正文组件承接完成、流式和等待显示；保持消息级操作、时间线顺序和页面滚动语义；以明确的有效模式隔离展示。

**Non-Goals:** 不把所有 AI 文本合并为一个新消息，不移动用户消息到另一区域，不新增独立窗口、富文本编辑器、Markdown 能力、导出按钮、数据库字段或语音协议。

## Decisions

1. **在同一时间线内呈现文本面板。** 新增 `AssistantOutputPanel.tsx`，作为 AI 输出区域的可复用展示组件，每条完成回复保留原 ID；流式区域使用相同正文样式。外观为可用宽度内的左对齐正文、自然换行、轮次间留白，无独立气泡底色和边框。不另建只包含 AI 的独立列表，避免破坏工具和用户输入的时序。保留现有时间分隔符。
2. **复用内容与消息操作。** 如需提取 `MessageBubble` 的正文、图片和元信息渲染，则只提取共用的展示部分，保持其现有默认行为。菜单继续绑定原始 Message，复制粒度仍是一条消息；不为流式文本伪造数据库 ID。无内容时不绘制空输出段。
3. **明确有效模式的生命周期。** ChatPage 在进入页面时读取保存的模式，连接启动时保存该次实际配置中的模式。连接中、通话中、自动重连时均使用此快照；明确结束或最终失败后恢复空闲选择。语音与已有 typed-input 启动路径都使用相同规则。历史消息按当前视图呈现，避免以当前数据库无法提供的历史模式做判断。替代方案为增加历史模式字段，会引入迁移且不符合本次展示范围。
4. **保留事件和滚动所有权。** 继续使用 ChatPage 的消息数据及流式回调，不在面板重新订阅 Relay。完成消息加载和临时文字清理作为同一轮交接处理，验证最终内容只出现一次。用户上滑时不强制滚动，现有滚动容器及最新位置锚点继续负责定位。不引入嵌套滚动区域。打断与断开沿用现有清理语义，不追加未经完成事件确认的历史消息。
5. **以真实 UI 边界验证。** 用户于 2026-09-21 明确确认：通过文本面板组件的可见内容，以及聊天页面的模式切换、流式输出和滚动行为验证。测试不读取组件私有状态，不搜索源码字符串断言实现。现有 Vitest 默认 Node 且只收集 `.test.ts`，计划新增局部 jsdom 环境、React Testing Library 和 `.test.tsx` 收集，不改变现有 Node 测试环境。测试 ChatPage 时仅替代 Electron IPC、WebSocket、媒体和剪贴板等外部边界，不替代内部 hooks 或展示组件。jsdom 中验证滚动意图和交互，真实布局、换行和像素位置通过 Electron 手动验收。

## Risks / Trade-offs

- [历史模式无法追溯] → 明确采用当前视图模式，不声称辨识旧消息来源，也不写回历史。
- [模式异步读取晚于会话启动] → 以实际启动配置快照为准，并防止旧的设置读取覆盖活动会话。
- [完成消息与 transient 交接重复] → 从外部事件输入驱动 ChatPage，等待持久化边界返回后断言单份可见正文；覆盖相邻回复，禁止按内容字符串全局去重。
- [提取共用展示误改普通气泡] → 为 Direct/Operator/Supervisor 和用户消息保留兼容检查。
- [重挂载导致阅读位置改变] → 稳定消息 key、共享滚动容器；真实窗口中检查流式完成前后的阅读位置。
- [测试依赖增长] → 仅增加开发依赖和局部 DOM 环境；现有 Node 测试继续原环境运行。
