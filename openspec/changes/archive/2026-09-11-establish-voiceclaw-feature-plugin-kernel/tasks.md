## TDD contract

The public seams below were confirmed during the pre-apply review. Every RED step first creates the named test and stated behavioral assertion. Missing tests, discovery failures, syntax errors, or unrelated setup failures do not count as RED. Each GREEN step is limited to the behavior named by that task; local cleanup follows only after the same test is green and the task-level command is rerun.
